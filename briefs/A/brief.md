# Brief A · Lajur

**Platform kursus mandiri skill kerja.** Produk fiktif untuk latihan.

## Produk

Perpustakaan kursus video skill kerja, misalnya spreadsheet, presentasi, komunikasi, dan manajemen waktu. Satu langganan untuk semua kursus, dengan uji coba gratis 7 hari. User belajar sendiri, kapan saja.

## User

Karyawan 22–35 tahun yang ingin naik level di pekerjaannya, dengan waktu terbatas di malam hari atau akhir pekan.

## Business goal

Pengunjung memulai uji coba gratis, lalu tetap berlangganan setelah uji coba selesai.

## Masalah UX utama

1. Terlalu banyak pilihan kursus, jadi user bingung mulai dari mana.
2. Banyak user berhenti di tengah kursus dan tidak kembali.

## Halaman

| | Wajib | Tambahan, kalau tempo cukup |
|---|---|---|
| P1 · Website SaaS | Beranda, Katalog kursus, Harga | Detail kursus, FAQ, Tentang |
| P2 · Web app | Beranda user ("Lanjutkan belajar"), Katalog dan pencarian, Halaman pelajaran | Sertifikat, Profil dan langganan |

## Data contoh

Ada di `data/`. Pakai isi ini, jangan mengarang sendiri.

- `courses.json`: 12 kursus dalam 4 kategori, masing-masing dengan pelajaran
- `plans.json`: 2 paket harga, bulanan dan tahunan
- `user.json`: 1 user (Rina) dengan 2 kursus berjalan
- `testimonials.json`: 3 testimoni
- `faq.json`: 5 pertanyaan
