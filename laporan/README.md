# Laporan

Diisi otomatis oleh Claude Code. Jangan dihapus.

- `pekan-N-log.md`: catatan setiap permintaan ke Claude Code dan tanggapanmu, ditulis sambil jalan.
- `pekan-N.md`: laporan pekan N dari `/laporan`, dengan refleksi yang kamu tulis sendiri.
- `akhir.md`: laporan akhir dari `/laporan akhir`, bahan presentasi pekan 10.

Laporan dikirim ke fasilitator lewat link repo, bersama hasil Track Taste.
